# 메일 위협 초기 분석기

메일 보안 지원, 침해 대응, 품질보증(QA), 영업 데모에서 `.eml` 원본을 빠르게 점검하는 로컬 우선 도구입니다. 웹 분석기는 모든 처리를 브라우저 안에서 수행하며 메일 데이터를 서버로 전송하지 않습니다.

## 웹에서 바로 사용

**웹 분석기:** https://llxerll.github.io/mail-threat-triage/

### 주요 기능

- 최대 100개 EML 일괄 분석과 위험도별 대시보드
- 제목·발신자·파일명 검색 및 판정별 필터
- SPF, DKIM, DMARC 결과와 From / Reply-To / Return-Path 불일치 점검
- 실행 파일, 매크로 문서, 압축 파일, 이중 확장자, 양방향 문자 파일명 탐지
- 퓨니코드, IP 직접 연결, 단축 URL, 과도한 하위 도메인, 링크 표시/실제 목적지 불일치 탐지
- 파일 전체 SHA-256과 URL 도메인·첨부파일 지표 추출
- 개별/통합 HTML 보고서, 전체 JSON, 요약 CSV 내보내기
- 모바일 화면과 드래그 앤 드롭 지원

파일당 최대 크기는 25MB이며 한 번에 100개까지 분석합니다.

## 판정 기준

탐지 항목별 가중치를 합산해 0~100점으로 표시합니다.

- 0~19점: 낮은 위험
- 20~49점: 의심
- 50~100점: 높은 위험

점수는 초기 분류의 우선순위를 정하기 위한 값입니다. 인증 헤더는 수신 시스템이 기록한 결과를 읽으며, 이 도구가 DKIM 서명을 직접 암호 검증하지는 않습니다. URL 평판 조회, 첨부파일 샌드박스, 메일 보안 게이트웨이를 대체하지 않습니다.

## 명령줄에서 사용

Python 3.10 이상이 필요하며 외부 패키지는 사용하지 않습니다.

```bash
python mail_triage.py 의심메일.eml
python mail_triage.py 의심메일.eml --format html -o 보고서.html
```

종료 코드는 `0` 낮은 위험, `1` 의심, `2` 높은 위험입니다.

## 테스트

```bash
python -m unittest -v test_mail_triage.py
```

## 안전한 사용

- 원본이 아닌 메일 복사본을 분석하세요.
- 추출된 첨부파일을 직접 열지 마세요.
- 웹 분석기는 선택한 파일을 업로드하거나 저장하지 않습니다.
- 외부 API를 호출하지 않으므로 평판 기반 판정은 포함되지 않습니다.
